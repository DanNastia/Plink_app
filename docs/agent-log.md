# Журнал взаимодействия агентов

При передаче результата добавьте строку в конец таблицы. Запишите дату в формате ГГГГ-ММ-ДД, реальную участницу и модель, имя скилла, пути к входам и выходам. В результате проверки укажите способ и наблюдение. Для невыполненной проверки запишите причину. Ссылку на PR можно добавить после его открытия.
